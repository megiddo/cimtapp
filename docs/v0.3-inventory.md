# 3. Inventory revisions (v0.3)

Unify **vials**, **BAC bottles**, and **syringe types** as stock items: each has **burn-down** and **open vs archived**. Peptide catalog rows (`peptide-types`) are **not** inventory.

**API/schema landed** on `0.3.2-backend-inventory` (`v0.3.2`): `StockItem` + `ArchivePolicy` + `StockList`, schema v7, `GET ?view=all`, `POST /syringes/{id}/archive`, PATCH no longer closes via `is_open`. Client list fetchers and syringe Archive button are on this branch. **Sheet vs full-list SPA pages** (and chrome titles) stay [milestone 1](v0.3-frontend-patterns.md).

## Today vs target

| Kind | Burn-down today | Open/archived today | Inventory sheet today |
| --- | --- | --- | --- |
| Vial (`compounds`) | Remaining mg/mL from uses + adjustments | `is_open` **and** `archived_at` (two flags) | Non-archived, including **closed** vials |
| BAC (`bac_bottles`) | `remaining_ml`; `POST …/burn` | `archived_at` only (no `is_open`) | `archived_at IS NULL` |
| Syringe (`syringe_profiles`) | `quantity`; restock / burn counts | **None** — nothing hides | **All** types |

**Target:** one lifecycle for all three kinds.

- **Open** = on the inventory sheet. Remaining can be > 0 or 0 (empty, not yet archived).
- **Archived** = off the sheet. Reached by an explicit archive action when remaining is **0**. Same 422 if remaining > 0.
- Drop vial **`is_open` as a separate “closed but still on the sheet” state.** A vial that is not archived is open. Logging and Home use **open (not archived)** vials only. Migrate existing `is_open = 0 AND archived_at IS NULL` rows to `archived_at = now` **only if remaining is 0**; if remaining > 0, set them open (`archived_at` null) so stock is not hidden.

## Burn-down (all kinds)

| Kind | Remaining | How it burns | Manual correction |
| --- | --- | --- | --- |
| Vial | mg and mL | Logged uses | `POST /compounds/{id}/adjust` remaining mL (keep) |
| BAC | mL | Mixes + `POST /bac-bottles/{id}/burn` | PATCH remaining if already present; keep burn |
| Syringe | integer count | `POST /syringes/{id}/burn`; restock adds | Restock stays |

Sheet cards always show **remaining** (already true for all three). Empty open items stay on the sheet until archived (today’s vial/BAC rule, now also syringes).

## Sheet vs full list

**`GET /inventory` (SPA `/inventory`)** lists **open only**, grouped as today: Vials, Bacteriostatic water, Syringes.

Under **each** heading, after the cards (or empty state), a text link:

- Vials → `/inventory/vials` (“Full list”)
- BAC → `/inventory/water` (“Full list”) — today’s `[id]` edit stays `/inventory/water/{id}`
- Syringes → `/inventory/syringes` (“Full list”) — edit stays `/inventory/syringes/{id}`

**Full list pages** show **all** items of that kind, two subheadings: **Open** then **Archived**. Archived rows are still links to the existing edit/detail route (read-only archive copy as today).

Do not put archived items on Home, Log vial pickers, or “current” BAC.

## API

List endpoints used by the **sheet** stay default **open only**.

| Change | Detail |
| --- | --- |
| `GET /compounds` | Keep excluding archived. Add `GET /compounds?view=all` (or `include_archived=1`) for the full list, ordered open first then archived, each group `compounded_at DESC`. |
| `GET /bac-bottles` | Same query flag. |
| `GET /syringes` | Sheet: `archived_at IS NULL`. Full list: `view=all`. |
| `PATCH /compounds/{id}` | Stop accepting `is_open` as a close-without-archive. Archive remains `POST /compounds/{id}/archive`. |
| `POST /syringes/{id}/archive` | New. 422 if `quantity > 0`. Sets `archived_at`, same copy as vials/BAC. |
| Schema | `syringe_profiles.archived_at` nullable. User-store strategy **v7**. |

Response DTOs: every stock item includes `archived_at` and a computed `remaining_*` (vial already has remainder; syringe `quantity`; BAC `remaining_ml`).
