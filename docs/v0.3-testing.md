# 0. Testing floors (v0.3)

Coverage and mutation stay **gates**, not dashboards. v0.3 **lowers line coverage** and **unifies mutation** so pattern splits and inventory work can land without chasing equivalent mutants.

## Target floors

| Tool | Metric | Fail below | Config to change |
| --- | --- | --- | --- |
| PHPUnit | Line coverage of `backend/src` | **90%** | `backend/scripts/check-coverage.php` (today **95%**) |
| Vitest | Line coverage of `frontend/src/lib/**/*.ts` | **90%** | `frontend/vite.config.ts` `test.coverage.thresholds` (today **95%**) |
| Infection | MSI **and** covered MSI | **80** / **80** | `backend/infection.json5` `minMsi` / `minCoveredMsi` (today 80 / **85**) |
| Stryker | Mutation score | **break 80**, **high 80** | `frontend/stryker.config.json` `thresholds` (today break **70**, high 80) |

Also update the table in [WORK-CHECKLIST.md](WORK-CHECKLIST.md) and [TESTING.md](TESTING.md) in the same PR that changes the scripts.

## Why these numbers

- **90% line coverage** still excludes tests, vendor, generated files, and `backend/public/` hashed SPA. 95% fought equivalent `parent::__construct` / shred-cleanup lines and slowed inventory work. 90% is the floor for the refactor; crypto wrap/unwrap, remainder, archive, and auth must stay covered.
- **80% mutation** is one number for PHP and JS. Infection `minCoveredMsi` drops from 85 to 80 (same as MSI). Stryker **break** rises from 70 to 80 so the SPA client is held to the same bar as PHP domain code. Markup-only `.svelte` files stay **out** of the Stryker mutate glob (`src/lib/**/*.ts` only) unless a later PR extracts testable view-models into `lib/`.

Do not disable mutators globally. Keep today’s Infection excludes (empty `SettingsInterface`, `Domain/DomainException`).

## How to measure (unchanged commands)

```bash
cd backend && composer test          # PHPUnit clover + check-coverage.php
cd backend && composer infection     # min MSI 80 / covered 80
cd frontend && npm test              # vitest --coverage, 90% lines
cd frontend && npm run mutation      # Stryker break 80
```

Docker: `make test`, `make infection`, `make mutation`.

## Implementation notes

1. Change the four config numbers **first** in the v0.3 PR that starts the backend split, and name **v0.3.x** in that PR body.
2. New TypeScript extracted from pages **must live under** `frontend/src/lib/` so Vitest/Stryker see it.
3. New PHP types under `backend/src/` are in the PHPUnit/Infection denominator on the next run.
4. Targeted Infection (`--filter=UserStore.php`) is for local review only; CI still runs full `composer infection`.
