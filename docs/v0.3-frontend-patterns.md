# 1. Frontend design-pattern mapping (v0.3)

Every production module under `frontend/src` (except `*.test.ts`) is assigned named patterns. Pages today are **Page Controllers**: fetch, validate, mutate, navigate, and render in one file.

**Rule after the split:** `lib/` holds Facades, Mappers, ViewModels, and Policies (Vitest/Stryker). `.svelte` files are Presentational or thin containers.

## Layout / chrome

### `routes/+layout.ts`

- **Current:** **Front Controller** / Auth **Guard** (session probe, redirect).
- **Target:** Keep. Prefer `readAction`/`isMe` inside `probeSession` so parse paths unify.

### `routes/+layout.svelte`

- **Current:** App **Shell Composite**.
- **Target:** Keep. Optional split: `TopBar.svelte`, `TabBar.svelte`.

### `lib/chrome.ts`

- **Current:** Config **Singleton** + path **Strategy** (`titleForPath`, `backHrefForPath`, sticky CTA).
- **Issues:** Regex title chain is brittle; full-list routes must be added here.
- **Target:** `RoutePolicy[]` (`test` + `title` + `backHref`). Policies for `/inventory/vials`, `/inventory/water`, `/inventory/syringes` indexes.
- **Split:** `chrome/tokens.ts`, `chrome/nav.ts`, `chrome/policy.ts`.

### `app.css`

- **Current:** Design **tokens** + layout template + primitive catalog (one 710-line file).
- **Issues:** Token duplication vs `CONTENT_MAX_PX`; `.auth-form` is a generic form.
- **Target:** `@layer` / files: `tokens`, `shell`, `forms`, `lists`, `feedback`, `modals`. New classes: `inventory-full-list`, `stock-group`. Split CSS **after** components exist.

### `app.d.ts`, `app.html`

- Ambient types / document shell. Not a split target.

## API / session / account

### `lib/api.ts`

- **Current:** Transport **Facade** + URL **Builder**.
- **Issues:** Two fetch styles (`apiJson` vs `readAction` in auth).
- **Target:** Transport only.
- **Split:** `lib/api/url.ts`, `lib/api/fetch.ts`, **`lib/api/actions.ts` (`readAction` moved from auth)**.

### `lib/payload.ts`

- **Current:** **Mapper** + **Specification** (`isValidationError`, `firstFieldError`).
- **Target:** Keep. Optional `FieldError.svelte`.
- **Split:** `payload/types.ts`, `parse.ts`, `errors.ts` if the file grows.

### `lib/auth.ts`

- **Current:** Fat **Facade** (credentials, `isMe`, `readAction`, export, store-backup, blob download).
- **Issues:** `readAction` is the app-wide gateway, not auth.
- **Target:** Split Facades.
- **Split:**
  - `lib/auth/me.ts` — `Me`, `isMe`, `normalizeEmail`
  - `lib/auth/credentials.ts` — login/register/logout/setPassword
  - `lib/auth/export.ts` — sqlite download
  - `lib/auth/storeBackup.ts` — GET/POST `.enc.bak` restore
  - `lib/api/actions.ts` — `readAction`
  - `auth.ts` — temporary barrel

### `lib/session.ts`

- **Current:** **Guard** + probe **Facade**.
- **Target:** Keep. Optional `session/redirect.ts` vs `probe.ts`.

### `lib/offline.ts`

- **Current:** **Decorator** (`saveWhileOnline`). Applied inconsistently (edits yes, many creates no).
- **Target:** Keep; use from `runDomainMutation`. Optional `OfflineToast.svelte`.

### `lib/health.ts`

- **Current:** Health **Facade**. **Keep**; use `apiUrl`.

## Tests (`*.test.ts`)

Follow the module they specify. Split `inventory.test.ts` / `auth.test.ts` with the Facades. `version.test.ts` stays a format **Specification**. Route `.svelte` stays out of Vitest/Stryker unless logic moves to `lib/` ([testing](v0.3-testing.md)).
