# 2. Backend design-pattern mapping (v0.3)

Every production class under `backend/src` is assigned named patterns. **Keep** means the class already is that pattern; **split** is the implementation cut.

HTTP `*Action` classes are **Command** objects on a **Template Method** (`Action` / `AuthenticatedAction`). They are listed in groups, not as 50 identical essays.

## Layer rules after the split

| Layer | Allowed | Forbidden |
| --- | --- | --- |
| Action | Parse args, call one application service, map HTTP | SQL, remainder math, archive rules |
| Domain service | Rules + ports | `PDO` SQL strings (move to repositories) |
| Repository | SQL in/out, row ↔ entity | Validation copy, HTTP |
| `UserStore::withUnlocked` | Unit of Work / identity map for one request | Business rules |

## Application — Template Method + Command

### `Action` (`Application/Actions/Action.php`)

- **Current:** Template Method (`__invoke` → `action()`), plus JSON `respondWithData`.
- **Issues:** Mixes HTTP plumbing with payload encoding.
- **Target:** Keep Template Method. Extract **Builder** `ActionPayloadFactory` only if error mapping keeps growing.
- **Split:** none required.

### `AuthenticatedAction` (`Application/Actions/AuthenticatedAction.php`)

- **Current:** Template Method + **Unit of Work** (always `withUnlocked`).
- **Issues:** Export/restore **must not** subclass this (writeback would clobber `.enc.bak` restore). Easy to get wrong.
- **Target:** Keep Template Method + Unit of Work. Optionally `ReadOnlyAuthenticatedAction` using a future `withUnlockedRead` if export-style no-writeback reads proliferate. **Never** put Export/Restore here.
- **Split:** optional `UnlockedSession` port wrapping `withUnlocked` so tests fake UoW without Slim.

### `ActionPayload`, `ActionError`

- **Current:** DTO / Value Object for JSON envelope.
- **Target:** Keep DTO.

### Stereotyped Commands (keep as Command)

Thin subclasses: construct domain service, call one method, `respondWithData`. **No split** unless a method grows SQL.

**Auth:** `RegisterAction`, `LoginAction`, `LogoutAction`, `GoogleStartAction`, `GoogleCallbackAction` — Command; Google pair is **Adapter** to OAuth redirect. Extract `SessionIssuer` (create session + cookie) shared by Register/Login/GoogleCallback. Optional `GoogleCallbackHandler` Domain Service so the action only redirects.

**Me:** `ViewMeAction`, `SetPasswordAction` — Command. `ExportUserAction`, `ViewPreMigrationBackupAction`, `RestorePreMigrationBackupAction` — Command **without** `AuthenticatedAction`; they typehint the widened `UserStorePort`. Leftover: shared `RequireAuthContext` helper (still **no** unlock UoW). Optional `MeQueryService` for `ViewMeAction` remainder assembly.

**Profiles / catalog / syringes / bac / compounds / uses:** `Create*`, `List*`, `View*`, `Patch*`, `Delete*`, `Burn*`, `Restock*`, `Archive*`, `AdjustCompoundAction`, `CurrentCompoundAction`, `ListOpenCompoundsAction`, `CreatePeptideTypeAction`, `ListPeptideTypesAction`, Health `HealthAction`.

**Inventory Commands (v0.3.2):** `ArchiveSyringeAction` same Command shape as `ArchiveCompoundAction`. List actions take `view=all` via `StockList::fromQuery`.

### `HttpErrorHandler`, `ShutdownHandler`, `ResponseEmitter`

- **Current:** Chain of Responsibility (Slim error middleware) + Template Method; `ResponseEmitter` is a **Decorator** of Slim’s emitter; `ShutdownHandler` is a shutdown **Observer**.
- **Target:** Keep. Optional `ExceptionMapper` — domain exception → (status, `ActionError`).

### `SessionAuthMiddleware`

- **Current:** Chain of Responsibility + **Decorator** of the request (`AuthContext`). Unwraps DEK; does **not** open the user store (good).
- **Issues:** Name vs `AuthenticatedAction` is confusing.
- **Target:** Keep CoR. Optional `AuthContextFactory` — sessionId → AuthContext.

### `BootServices`

- **Current:** Facade for boot (global migrate).
- **Target:** Keep Facade.

### `Settings`, `SettingsInterface`, `EnvValidator`

- **Current:** Settings is a DTO; interface is empty-ish port; EnvValidator is **Builder** + **Specification** (valid AMK/URL) plus env merge + Google key assert.
- **Target:** Keep Validator. Optional: `EnvMerger`, `GoogleEnvGuard`; typed `AuthSettings` / `CryptoSettings` later.
- **Keep:** Infection already excludes empty `SettingsInterface`.

## Domain — Auth

### `AuthService`

- **Current:** Fat **Facade** / God Domain Service (register, password login, Google, set password, `meFromUserDb`).
- **Issues:** Google attach + provision + DEK mint in one type.
- **Target:** **Application services** (use cases): `RegisterAccount`, `LoginWithPassword`, `LoginWithGoogle`, `SetPassword`. `AuthService` becomes a **Facade** that delegates, or is deleted.
- **Split:**
  - `PasswordAuthService` / `RegisterAccount` + `PasswordLogin` — validate, hash, dummy-hash timing
  - `GoogleAuthService` / `GoogleLogin` — verified email, sub/email attach rules
  - `AccountSyncService` — setPassword + provisioner sync
  - `MeIdentityReader` / `AccountSnapshot` — `meFromUserDb`
  - keep `createUser` as private helper or `UserFactory` — mint DEK, wrap, insert, provision

### `UserProvisioner`

- **Current:** Factory for user row + encrypted store + seed syringe.
- **Target:** Keep **Factory**. Optional: `AccountTableWriter` + `DefaultSyringeSeeder` (Dose, not Auth). Seed syringe via `SyringeFactory` after inventory split.

### `SessionService`, `Session`

- **Current:** Service + Entity/Value Object.
- **Target:** Keep. `Session` stays VO/entity.

### `User`, `AuthContext`

- **Current:** Entity / Context Object (security session).
- **Target:** Keep. `toMeArray` is a **Mapper**; move to `MeMapper` if `User` grows.

### `UserRepository`, `SqliteUserRepository`

- **Current:** Port + Adapter. **Keep.**

### `OauthState`, `OauthStateService`, `OauthStateRepository`, `SqliteOauthStateRepository`

- **Current:** Entity, Service, Port, Adapter. **Keep.**

### `AuthRateLimiter`, `RateLimitRepository`, `SqliteRateLimitRepository`

- **Current:** Service + Port + Adapter. **Keep.**

### `PasswordHasher`, `EmailNormalizer`, `IdGenerator`, `Clock` / `SystemClock`, `CredentialParser`

- **Current:** Strategy/Service + Port/Adapter for clock. `PasswordHasher::dummyHash()` is a **Null Object** for timing-safe unknown email. `CredentialParser` is a sibling of `FieldParser`. **Keep.**

### `GoogleOAuthClient`, `GoogleUserInfo`

- **Current:** Port + DTO. League adapter in infra. **Keep.**

### Auth exceptions (`AuthenticationException`, `GoogleOAuthException`, …)

- **Current:** Marker domain exceptions. **Keep** (Null Object not needed).

### `UserStorePort`

- **Current (v0.3.2):** Port includes `create`, `withUnlocked`, `exportPlaintext`, `hasPreMigrationBackup`, `restorePreMigrationBackup`. Me export/restore/view-backup actions typehint the port and still extend `Action` only (not `AuthenticatedAction`).
- **Leftover:** optional read-only unlock / `RequireAuthContext` helper.

## Domain — Dose / inventory (main spaghetti)

### `CompoundService`

- **Current (v0.3.2):** Still a Transaction Script Facade, but list takes `StockList`, archive delegates to `ArchivePolicy` + `CompoundStock`, and `is_open` is derived (`archived_at === null`). PATCH/create ignore `is_open` as a close-without-archive flag.
- **Issues:** Mixed persistence, remainder, DTO mapping, SQL still in the service.
- **Target:** Entity + Repository + small services.
- **Split:**
  - `Compound` entity — identity, mix fields, `archivedAt`
  - `CompoundRepository` — list/current/find/insert/update/delete/archive SQL
  - `CompoundPresenter` / `CompoundMapper` — `present`, `remainderSummary`
  - `CompoundMixService` — create/patch mix, BAC debit, profile links
  - `CompoundAdjustmentService` — adjust + assertMixFitsUses + syncUseDoses
  - `CompoundArchiveService` — archive rules (or shared `ArchivePolicy`)
  - `CompoundQueryService` — list/listOpen/current/get/remainders
  - Keep `CompoundService` as a thin **Facade** if Action DI should stay stable
  - `RemainderCalculator` (existing `DoseCalculator` + `Remainder` VO) — keep; call from query/mix path

### `BacBottleService`

- **Current (v0.3.2):** List takes `StockList`; archive delegates to `ArchivePolicy` + `BacStock`. SQL still in the service.
- **Target:** Same split: `BacBottle` entity, `BacBottleRepository`, `BacLedger` (debit/credit/mix delta), `BacBottleLifecycle` (burn/archive).

### `SyringeService`

- **Current (v0.3.2):** CRUD, default, fallback, restock/burn, open-only / `view=all` lists, `archived_at` on DTOs. **No** `archive()` — syringes archive through `ArchivePolicy` + `SyringeStock`.
- **Issues:** Fallback syringe is a **Null Object** hiding in the service.
- **Target:**
  - `SyringeType` entity + `archivedAt`
  - `SyringeRepository` — CRUD/map/find/default
  - `SyringeResolver` / `FallbackSyringe` **Null Object** (today `fallbackProfile()`)
  - `SyringeStockService` / `ChangeStockCount` — restock/burn/consumeOne
  - `ArchiveStock` adapter (do **not** copy-paste a fourth `archive()`)

### `UseService`

- **Current:** God script: create/list/patch/delete, last syringe per profile, remainder checks, SQL joins.
- **Target:**
  - `LoggedUse` entity
  - `UseRepository` — list/get/insert/update/delete SQL + map
  - `UseWriteService` / `LogDose` — create/patch/delete + overdraw + syringe/profile/compound resolution
  - `UseQueryService` — list with before/limit/`profile_id`
  - `MigrateUseProfile` — patch `profile_id` without vial association (legacy rule)

### `ProfileService`

- **Current:** Small Transaction Script (CRUD, default, cap 5).
- **Issues:** SQL in domain.
- **Target:** `Profile` entity + `ProfileRepository`. Keep cap/default rules in `ProfilePolicy` **Specification**. Extract `CompoundProfileLinker` for `compound_profiles` junction writes.

### `UserPeptideService`

- **Current:** Composite catalog (global `PeptideCatalog` + per-user rows) + slug factory. **Split:** `UserPeptideRepository`, `PeptideSlugger`.

### `PeptideCatalog` / `SqlitePeptideCatalog`

- **Current:** Port + Adapter. **Keep.**

### `DoseCalculator`

- **Current:** Domain Service / **Strategy** for IU↔mL↔mg. **Keep.**

### `Remainder`

- **Current:** Value Object. **Keep.**

### `DoseConfig`

## Inventory port (landed v0.3.2)

### `StockItem` (interface)

- **Pattern:** Port.
- **Methods:** `id()`, `kind()`, `remaining()`, `isArchived()`, `archive(Clock)`.

### `ArchivePolicy`

- **Pattern:** Strategy / Specification.
- **Rule:** remaining == 0 (`DoseCalculator::isDepleted`), not already archived.

### `StockList`

- **Pattern:** Query Object.
- **`openOnly()` vs `allGrouped()`** (open then archived). `fromQuery` treats `view=all` as grouped.

### Adapters

`CompoundStock`, `BacStock`, `SyringeStock` implement `StockItem`. Compound/BAC `archive()` methods delegate to the policy; `ArchiveSyringeAction` calls the policy directly. No `SyringeService::archive()`.

## Infrastructure — persistence

### `UserStore`

- **Current:** Facade + Unit of Work + Template (lock, decrypt, migrate, callback, encrypt, shred). Snapshot `.enc.bak` is extra policy inside UoW.
- **Issues:** Large; snapshot/restore mixed with I/O.
- **Target:** Keep UoW facade.
- **Split:**
  - `UserStoreLock` / `ExclusiveUserLock` — flock polling
  - `UserStoreCipherSession` / `PlaintextSession` — decrypt → callback → encrypt/shred (shared by `withUnlocked` and `exportPlaintext`)
  - `PreMigrationBackup` / `EncSnapshot` — copy `.enc` → `.bak`, has/restore/copyAtomic
  - `UserStore` — Facade implementing the **widened** Port

### `UserMigrator`, `UserSchemaCatalog`, `UserSchemaVersionDetector`

- **Current:** **Strategy** catalog + **Chain** of version steps + **Interpreter** of schema shape.
- **Target:** Keep Strategy. Detector is **Specification** (shape vs table vs filename).

### `UserSchemaStrategy`, `SqlFileUserSchemaStrategy`, `CreateInitialUserSchema`, `AddBacAndSyringeStock`, `AddUserPeptideTypes`, `AddNamedOpenVials`, `AddArchiveAndAdjustments`, `AddProfiles`, `AddSyringeArchive`

- **Current (v0.3.2):** Strategy + Template Method (SQL file). **v7** `AddSyringeArchive` adds `syringe_profiles.archived_at` and backfills closed vials (archive only if remaining is 0). `AddProfiles` still constructs `new IdGenerator()` for Default seed.
- **Target:** Keep Strategy. Inject `DefaultProfileBackfill` (seed Default + link uses/compounds); strategy only runs SQL then delegates. Do **not** force-unify user Strategy catalog vs global file-list `SqliteFileMigrator` — two styles are intentional.

### `UserStoreFormat`

- **Current:** Enum / Type Object. **Keep.**

### `DataPaths`

- **Current:** Value Object / **Factory** of paths. **Keep.**

### `SqliteFileMigrator`, `GlobalMigrator`, `GlobalConnection`

- **Current:** Template Method + Facade for global sqlite. **Keep.**

### `SqliteSessionRepository` and other Sqlite* repositories

- **Current:** Adapter. **Keep.**

### `UserStoreException`, `UserStoreLockedException`

- **Current:** Exceptions. **Keep.**
